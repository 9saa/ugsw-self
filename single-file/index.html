Site policy

Privacy note

Last updated 28 October 2026

UGSW is a static catalogue with no accounts, no advertising, and no analytics. The catalogue itself does not set cookies. It stores a small amount of interface state in your browser's localStorage so that searches and the last game survive a refresh. Individual game files are third-party and may use their own storage or cookies; those choices are theirs, not the catalogue's.

What is stored on your device

  • The theme you picked (ugsw:theme).
  • The catalogue search and scroll position (ugsw:view).
  • Up to eight recently played game files (ugsw:recent) and the last one opened (ugsw:last).
  • The last YouTube search and result tab, the last proxy address, and recent Spotify items, if you used those tools (ugsw:yt, ugsw:proxy, ugsw:spotify).

This information stays on your device. You can remove it with the “Clear history” button in the catalogue's recently played section, or by clearing site data for this origin in your browser.

Network requests

The catalogue, stylesheets, and game files are loaded from this site. Typefaces are requested from Google Fonts, which receives that request. Individual game files may load their own assets from third-party services such as CDNs; those requests are made by the game, and those services receive the usual request information (IP address, user agent, requested URL) under their own policies.

The YouTube tool sends your query to the UGSW backend, which fetches YouTube's public results page. The proxy tool sends the address you enter to the same backend, which fetches that page and returns it. The Spotify tool sends searches and links to the backend, which may query Spotify's API or a public web index to resolve them. The AI tool sends the conversation you type to the same backend, which forwards it to the model provider to generate a reply; the site does not store the conversation. The backend is served from api.ugsw.fun through Cloudflare. Video playback uses youtube-nocookie.com; Spotify playback uses open.spotify.com's embed. YouTube, Google and Spotify handle those embeds under their own policies.

The backend may be password-gated for the proxy. It does not create accounts and does not set cookies for this site. Requests to the backend are processed by Cloudflare and the service behind it under their terms.

Questions

The project's public chat is the UGSW Discord. The source document for the catalogue is the Ultimate Game Stash document.

Using the tools
